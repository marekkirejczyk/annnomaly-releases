# ANИNOMALY — downloads

Builds of **Annnomaly**, a free first-person puzzle game about broken time.

The game's site, with footage and instructions: https://annnomaly.vercel.app

Get the files from the [latest release](../../releases/latest):

| System | File |
| --- | --- |
| macOS (Apple Silicon or Intel) | `Annnomaly-<version>-macos-universal.zip` |
| Windows 10 / 11, 64-bit | `Annnomaly-<version>-windows-x64.zip` |
| Linux, x86-64 | `Annnomaly-<version>-linux-x64.tar.gz` |

This repository holds the downloadable builds only.
